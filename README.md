"Make the AI Judge Feel Nostalgic: A Childhood Memory".

`main.ts` (Node 22, no dependencies) writes one sentence — a single childhood
memory — to `/output/entry.txt`:

> Every night the gate creaked, my father's motorbike headlight swept across
> the cracks in my bedroom wall, and I lay still, pretending to be asleep, so
> he would believe his long day had ended well.

Run it with:

```sh
node main.ts
```
